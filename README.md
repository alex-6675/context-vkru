# Edge-расширение для VK.RU

**СТАТУС: РАЗРАБОТКА НАЧАТА — идёт сборка структуры проекта (каркас).**

> ⚠️ **ВАЖНО:** Расширение предназначено **только для десктопной версии браузера Microsoft Edge**. Мобильные платформы и другие браузеры не поддерживаются.

Полное архитектурное описание перенесено в [develop/docs/architecture.md](develop/docs/architecture.md).

## О проекте

Браузерное расширение для Microsoft Edge (Manifest V3), создающее **собственный UI-слой** (маркеры, бейджи, контекстные заметки) поверх портала `https://vk.ru/`. Расширение не модифицирует внутреннюю логику VK.RU, а лишь точечно взаимодействует с сущностями (персонами, сообществами).

## Текущий этап

- Собирается каркас структуры проекта (только заглушки с комментариями).
- Реализацию кода ведёт отдельная LLM на следующем этапе.
- Подробная архитектура, границы и контракт адаптера — в [architecture.md](develop/docs/architecture.md).
