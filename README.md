# context-vkru

> **СТАТУС: АРХИВ** · донор ядра для территорий **m3** и **mem** · вход — через **m3 / mem**
>
> Эта территория закрыта (TASK-0102). Разработка продолжается в `m3`
> (каркас «Мои записки») и `mem` (трек mem-2026). context-vkru сохраняется
> как источник проверенного ядра и протоколов.

Точечные заметки и картотека персон/сообществ для **vk.ru** — Edge-расширение
(Manifest V3, Vanilla JS, ноль зависимостей) + журнал процесса (React-дашборд).

## Что здесь

- **`EdgeExtension/`** — ядро расширения. Ключевое архитектурное решение —
  собственный слой-«стекло» (`src/ui/layer.js`): отрисовка маркеров по координатам
  поверх портала, без инъекции в чужой DOM (React vk.ru её стирает). Скальпель —
  доступ браузера «при нажатии», индикатор трёх состояний на значке.
- **`dashboard/`** — журнал процесса: сверка с архитектурой, дорожная карта
  v01–v15, реестр заданий, итоговые листы сборок.
- **`docs/`** — архитектура, дополнения (контракт карточки v2, DB v3), задания
  `TASK-0001…0102`, трек С (ОК-реальность), финальный аудит (`audit-final.md`).
- **`reports/`** — протоколы ручных проверок (RESULT) по каждой сборке.
- **`scripts/`** — сборка, чистка, тесты, запуск Edge c CDP (:9222) и
  миграция в m3 (`migrate-to-m3.ps1`, provenance по SHA256).

## Перенос в m3

Каркас m3 и перенос ядра — `scripts/migrate-to-m3.ps1`:

```powershell
pwsh scripts/migrate-to-m3.ps1              # m3 рядом: ..\m3
pwsh scripts/migrate-to-m3.ps1 -TargetRoot D:\m3
```

Копирует проверенные файлы КАК ЕСТЬ (с SHA256-хэшами в `m3/reports/migrate-m3-report.md`),
создаёт затычки («Мои записки» 0.1.0), docs и dashboard «прошлое–настоящее–будущее».
**Не переносит** wrap/unwrap-инъекции и мемориальные данные mem-2026.

## Процесс

Регламент — в `AGENTS.md` (Дополнения А/Б): код передаётся только закоммиченным
файлом, подчёркивания в селекторах — через `String.fromCharCode(95)`, статус
PASS/FAIL ставит только пользователь, факт — репо (`Б5`).
