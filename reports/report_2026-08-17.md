## РЕГЛАМЕНТ ЗАПУСКА СБОРКИ + ТЕСТ (простым языком)

### А. Дашборд (React/Vite) — запуск вручную

Это веб-инструмент (дашборд аудита). Он не собирается через PowerShell-скрипты расширения.

```powershell
cd dashboard
npm install
npm run dev
```

- Откроется локальный адрес (например, `http://localhost:5173`).
- `npm run build` — продакшен-сборка в `dashboard/dist/`.

### Б. Расширение (EdgeExtension) — сборка и тест

Основные скрипты проекта лежат в `scripts/` и рассчитаны на **PowerShell 7+** и **Windows**.

```powershell
# 1. Очистить артефакты сборки
.\scripts\Clean.ps1

# 2. Собрать расширение: копирует src/ → EdgeExtension/dist/
.\scripts\Build.ps1

# 3. Проверить целостность структуры (Test.ps1)
.\scripts\Test.ps1
```

Порядок:
1. `Clean.ps1` — удаляет старую папку `dist/` (если была).
2. `Build.ps1` — создаёт свежую `EdgeExtension/dist/` из `src/`.
3. `Test.ps1` — проверяет наличие ключевых файлов (manifest, background, content, модули, локали).

### В. Ручная загрузка расширения в Edge (тест)

Собранное расширение загружается в Edge **вручную** (режим разработчика):

1. Откройте `edge://extensions`.
2. Включите **«Режим разработчика»** (переключатель внизу слева).
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `EdgeExtension/` (или `EdgeExtension/dist/`).
5. Откройте `https://vk.ru/` и проверьте консоль страницы (F12 → Console).

### Г. Помощник запуска Edge с чистым профилем

Для тестирования без ваших личных данных в Edge:

```powershell
.\scripts\run-edge-vk-test.ps1
```

Скрипт откроет Edge с отдельным чистым профилем. Подробнее — в `docs/INSTRUCTION.md`.

## ДАЛЬНЕЙШИЕ ИНСТРУКЦИИ

- Вся реализация расширения ведётся строго по `docs/architecture.md` и `docs/РЕГЛАМЕНТ_РАБОТ.md` (источник истины).
- Сборки нумеруются `v_01`, `v_02`, ... Каждый этап — отдельный модуль, отдельная тестовая сборка.
- Отчёты по каждой сборке кладутся в `reports/` (формат: `BUILD.md` / `TEST.md` / `RESULT.md`).
- Статус `PASS`/`FAIL`/`BLOCKED`/`NOT TESTED` устанавливает только Пользователь после ручной проверки.
- Расширение предназначено **только** для десктопного Microsoft Edge и только для `vk.ru`.
