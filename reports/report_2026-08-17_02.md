## РЕГЛАМЕНТ ЗАПУСКА СБОРКИ + ТЕСТ

### Статическая проверка состава

```powershell
pwsh ./scripts/Test.ps1
```

Должно вывести все `[PASS]` по списку файлов v_01. PASS/FAIL по факту работы — только в Edge (см. `reports/v_01/TEST.md`).

### Сборка в zip

```powershell
pwsh ./scripts/Build.ps1   # → dist/context-vkru_v_01.zip
```

### Ручной тест в Edge

1. `edge://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `EdgeExtension/`.
2. Открыть `https://vk.ru/` → DevTools (F12) → Console.
3. Ожидаем строки: `[CTX v_01] service worker started` (в SW) и `[CTX v_01] content script active on vk.ru` (в консоли страницы).
4. Результат зафиксировать в `reports/v_01/RESULT.md` (заполняет только Пользователь, §5.6).
