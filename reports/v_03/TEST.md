# TEST · v_03 · VK.RU Adapter: обнаружение

## 1. Предусловия

- v_02 был PASS (RESULT_v_02.md); расширение уже загружено в Edge.
- Файлы v_03 на диске; в карточке нажата кнопка **Reload (⟳)**; версия **0.0.3**, без Errors.
- Открыты две консоли: страница (F12) и Service Worker (edge://extensions → inspect).
- Тестовая страница — страница сообщества со стеной и комментариями (та же, что в 3A.3).

## 2. Действия и наблюдения

1. Открыть тестовую страницу сообщества.
   **Консоль страницы:** `[CTX v_03] ENTITY FOUND: N new`, строки
   `COMMENT PERSON/…` с `id=/id…` или `/club…`, `post=wall-228585143_222`, `reply=…`.
2. Навести курсор в консоли на напечатанный `sourceElement` —
   в DOM подсвечивается **именно блок комментария** (доказательство привязки).
3. Сверить `id` автора со статус-строкой: навести мышь на автора комментария —
   URL внизу браузера совпадает с `id` в логе.
4. **Консоль SW:** `[CTX v_03] entities reported: N` + список сущностей.
5. Раскрыть тред («показать предыдущие комментарии») → через ~1 с дологгируются
   **ТОЛЬКО новые ответы**; существующие не дублируются (наблюдать 10–15 с — повторов нет).
6. Открыть `feed?w=wall-234325978_1730` → есть строки **POST** (автор `/id…`) и **COMMENT**.
7. Открыть `example.com` → тишина. PING/PONG работает (регрессия v_02).

## 3. Ожидаемый результат (PASS)

- Комментарии (включая треды) и посты обнаружены на реальной странице;
- `sourceElement` подсвечивает корректный блок;
- `id` совпадает с navigation target в статус-строке;
- дедупликация работает (нет повторов после F5 и при раскрытии треда);
- SW получил `ENTITY_FOUND`;
- ошибок на карточке расширения нет.

## 4. Признаки FAIL

- Нет строк `ENTITY FOUND` при наличии комментариев на странице
  (проверить написание data-testid в живом DOM — при несовпадении правка **внутри v_03**,
  см. примечание BUILD.md);
- `sourceElement` подсвечивает не тот блок; `id` не совпадает со статус-строкой;
- дубликаты сущностей после F5 / при раскрытии треда;
- красные ошибки в консолях; сломан PING/PONG (регрессия).
