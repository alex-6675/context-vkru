## РЕГЛАМЕНТ ЗАПУСКА СБОРКИ + ТЕСТ

### Обновление расширения в Edge

1. Заменить файлы `EdgeExtension/` на диске версией из репо (v_02).
2. `edge://extensions` → карточка «Context VK.RU» → кнопка **обновления (↻)**.
3. Проверить версию в карточке: **0.0.2**, красных ошибок нет.

### Ручной тест в Edge

1. В карточке расширения открыть «Service Worker» — консоль SW.
2. Открыть (или обновить) вкладку `https://vk.ru/` → F12 → Console страницы.
3. Ожидаем:
   - SW: `[CTX v_02] service worker started`, `[CTX v_02] PING received from tab N`, `[CTX v_02] PONG sent to tab N`;
   - страница vk.ru: `[CTX v_02] content script active on vk.ru`, `[CTX v_02] PING sent to background`, `[CTX v_02] PONG received from background (build v_02, rtt ~N ms)`.
4. Повторить после F5; на `example.com` — тишина.
5. Результат зафиксировать в `reports/v_02/RESULT_v_02.md` (заполняет только Пользователь, §5.6).
