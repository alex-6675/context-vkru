# BUILD · v_01 · Контрольный каркас

**МОДУЛЬ:** M-01 · **СБОРКА:** v_01 · **СТАТУС:** ожидает ручной проверки в Edge

## Состав сборки

| Файл | Назначение |
| --- | --- |
| `EdgeExtension/manifest.json` | Manifest V3: имя, версия 0.0.1, SW, content script, права |
| `EdgeExtension/src/background.js` | Service Worker: жизненный цикл + логирование |
| `EdgeExtension/src/content.js` | Content Script: сигнал запуска на `https://vk.ru/` |
| `reports/v_01/TEST.md` | Инструкция ручной проверки и PASS-критерии |
| `reports/v_01/RESULT.md` | Фиксация вердикта (заполняет Пользователь) |

## Архитектурные решения

- Только Vanilla JS, ноль зависимостей (РЕГЛАМЕНТ §2.2).
- Собственный UI-слой пока НЕ рисуется: `content.js` лишь сигнализирует о запуске.
- Идентификация сущностей НЕ реализуется — до подтверждения гипотез на живом DOM (§5.7).
- `host_permissions` ограничен `https://vk.ru/*` (architecture.md §B, §2.1).
- Поле `icons` в v_01 не объявлено (штатная иконка-«пазл»): манифест обязан загружаться
  без ошибок, а битовой графики в пакете пока нет. Фирменные 16/48/128 — отдельное
  косметическое уточнение после PASS, на критерии этапа не влияет.

## Ограничения v_01 (по плану)

- Нет обмена сообщениями (это v_02, PING/PONG).
- Нет адаптера `vkru.js` (это v_03+, только после диагностических snippet'ов).
- Нет popup / dialog / storage / contextMenus.

## Как загрузить

1. `edge://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `EdgeExtension/`.
3. Открыть `https://vk.ru/` → DevTools (F12) → вкладка Console.

Далее — `TEST.md`. Статус PASS/FAIL устанавливает только Пользователь (§5.6).
