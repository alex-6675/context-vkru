## Раздел: ЗАДАНИЯ КОДЕРУ (TASK)

Задания Кодеру ведутся нумерованными файлами `docs/tasks/TASK-XXXX.md`.
Каждый TASK — один модуль по принципу «один модуль → одна сборка → один
результат» (РЕГЛАМЕНТ v2.0, часть 4).

### Формат файла TASK

```
# TASK-XXXX — <commit subject>

КОММИТ: <type>(<scope>): <subject> [TASK-XXXX]
СТАТУС: ОЧЕРЕДЬ | ИСПОЛНЕНО | PASS | FAIL
ОБЛАСТЬ: ext | infra | docs | dashboard | env
ОСНОВАНИЕ: <отчёт проектировщика / цитата>
ЗАВИСИМОСТЬ: TASK-YYYY = PASS (или «нет»)

ЦЕЛЬ / ИЗМЕНЯЕМЫЕ ФАЙЛЫ / ЧТО СДЕЛАНО / КОД /
ТЕСТ / ОЖИДАЕМЫЙ РЕЗУЛЬТАТ (PASS) / СТОП
```

### Реестр группы (conventional commits, теги [TASK-XXXX])

| TASK | Коммит | Область | Статус | Зависимость |
|---|---|---|---|---|
| TASK-0001 | `feat(ext)` M-03r — ПКМ «Сохранить персонажа/сообщество», изъятие linkUrl | ext · 0.0.6 | ИСПОЛНЕНО, ждёт RESULT_v03r.md | — |
| TASK-0002 | `chore(infra)` RunEdgeCdp.ps1, .gitignore, tasks/launch, opencode.jsonc | infra | ОЧЕРЕДЬ | TASK-0001 = PASS |
| TASK-0003 | `docs` AGENTS.md — Дополнение А (целостность и гейты) | docs | ОЧЕРЕДЬ | нет |
| TASK-0004 | `style(dashboard)` строгий деловой дизайн, референс Gmail | dashboard | ОЧЕРЕДЬ | нет |
| TASK-0005 | `chore(env)` настройки workspace и рекомендации расширений | env (.vscode) | ОЧЕРЕДЬ | нет |

Правило: TASK-0005 (.vscode/) коммитится **отдельно** — не смешивая с кодом
расширения и дашбордом.

### Правила процесса

1. Код передаётся **только закоммиченным файлом**; перед тестом пользователя
   проектировщик верифицирует raw-файлы на GitHub (РЕПО-ГЕЙТ).
2. Подчёркивания в testid/URL-схемах — только через `String.fromCharCode(95)`
   (§25 РЕГЛАМЕНТА); копирование кода из рендер-вью чата запрещено.
3. Вердикт PASS/FAIL устанавливает **только Пользователь** (§5.6); при FAIL —
   итерация внутри сборки (§5.1), следующий TASK не выдаётся.
