# ПОПРАВКА: трек С — реальность вместо прожекта
0. Музей/кадетский класс = прожект (мечта, зарница);
   в базовый сценарий НЕ входит.
1. Реальный канал = ОК: аудитория 60+, внуки павших; в сети потому,
   что дети и внуки подарили старые смартфоны; ЦАМО не знают, но помнят
   имена бабушек, включая девичьи фамилии. 
2. Похоронка богаче «жена/мать»: сестра, тётя, без родства,
   фамилия ≠ фамилии павшего. В soldier v2 добавить:
   notify.relation (жена|мать|сестра|тётя|без указания|иное),
   notify.maiden (признак девичьей фамилии) — поисковые ключи.
   Важная нижняя строка персональной карточки = эти поля целиком.
3. Механика: OK API → персональные карточки бойцов в сообществе
   mem-2026 (быстрее ручного); после свёрстки — приглашение
   с верификацией, шаблон №2 (тезис; финальный текст чище, R10):
   «Прошу проверить ваше родство с ФИО павшего в ВОВ. Группа,
   содержащая карточку, готовит ходатайство на изготовление
   мемориальной плиты с данным ФИО и его боевыми товарищами.
   Если вы  имеете отношения к ФИО — оставьте комментарий,
   как с вами связаться, чтобы вызвать на открытие мемориала».
4. Офлайн-точки той же аудитории: сельские библиотеки, храмы —
   на карточку как точка контакта (venue) Важно(!)имеют страницы в OK.
5. Техника: OK = первоклассный портал mem-2026 (normalize ok,
   OK API сообщества), НЕ заглушка. В m3 OK-заглушка остаётся
   для личных записок — не смешивать.
