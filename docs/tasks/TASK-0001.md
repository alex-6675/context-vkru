**МОДУЛЬ:** M-03r · **СБОРКА:** v03r · **МАНИФЕСТ:** 0.0.6
**ОСНОВАНИЕ:** reports/v_03/M03r.md (Архитектурное решение №2), ветка main-qwen_v_03
**ЗАВИСИМОСТЬ:** нет (первый в группе)

## ЦЕЛЬ

Доказать: браузер в момент ПКМ сам отдаёт ссылку сущности (`linkUrl` / `pageUrl`).
Никакого массового сканирования. Только действие пользователя.

## ИЗМЕНЯЕМЫЕ ФАЙЛЫ

- `manifest.json` — ДОБАВИТЬ `"permissions": ["contextMenus"]` и `version: 0.0.6`;
  УБРАТЬ `src/adapters/vkru.js` из списка `content_scripts.js` (файл остаётся в репо на будущее)
- `src/core/messaging.js` — замена: `CTX_BUILD = "v03r"`, единственный тип `CAPTURED: "ctx:captured"`
- `src/background.js` — замена: `contextMenus.create` («Сохранить персонажа», «Сохранить сообщество»,
  `contexts: ["link"]`), `onClicked` → изъятие `{menu, link, page, ts}` → лог → `tabs.sendMessage`
- `src/content.js` — замена: приём `CAPTURED`, строка
  `[CTX v03r] captured | menu: … | link: … | page: …`

## ЧТО СДЕЛАНО

- Пункты меню появляются **только на ссылках** (`contexts: ["link"]`).
- Изъятие — напрямую от браузера: не выцарапываем из разметки, не зависим от vkit-*.
- Массовый сканер и MutationObserver сняты с обязанности (были избыточны по Решению №2).

## КАК СОБРАТЬ / ЗАГЛУЗИТЬ

Сохранить UTF-8 → `edge://extensions` → Reload (⟳) → версия **0.0.6** → F5 на vk.ru.

## ТЕСТ (три действия, скриншот)

1. ПКМ на имени автора любого поста → видны пункты «Сохранить персонажа» и «Сохранить сообщество».
2. Навести курсор на имя (внизу слева ссылка) и кликнуть «Сохранить персонажа» →
   консоль F12 (фильтр CTX): строка `captured | menu: save-person | link: … | page: …`,
   и **link совпадает** с тем, что было внизу слева.
3. ПКМ по пустому месту страницы → наших пунктов **НЕТ**.

## ОЖИДАЕМЫЙ РЕЗУЛЬТАТ (PASS)

Пункты есть только на ссылках; изъятая `link` совпадает со статус-строкой;
`page` = текущая страница; карточка без ошибок.
→ `RESULT_v03r.md` и dashboard, затем **TASK-0002 (v_04r)**.
