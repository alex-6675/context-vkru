2. **РЕПО-ГЕЙТ.** После итерации Coder коммитит `EdgeExtension/` в рабочую ветку;
   проектировщик верифицирует **raw-файлы** на GitHub ДО теста пользователем.
   Пользователь не тестирует до raw-верификации.
3. **Гейт вердикта.** Статус PASS/FAIL устанавливает только Пользователь (§5.6).
   LLM не объявляет тесты пройденными и не переходит дальше после FAIL (§5.1).
4. **Приёмочный гейт.** Самодиагностическая строка (coverage) делает порчу кода
   видимой мгновенно; отсутствие ожидаемой строки = СТОП и сообщить.
