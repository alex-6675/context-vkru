# TASK-0004 — style(dashboard): строгий деловой дизайн, референс Gmail

**КОММИТ:** `style(dashboard): строгий деловой дизайн, референс Gmail [TASK-0004]`
**СТАТУС:** ОЧЕРЕДЬ
**ОБЛАСТЬ:** `dashboard` — журнал процесса (React/Vite/Tailwind)
**ЗАВИСИМОСТЬ:** нет (поверх текущего журнала)

## ЦЕЛЬ

Привести дашборд к **строгому деловому стилю** по референсу Gmail: спокойная светлая
поверхность, плотная типографика, аккуратные разделители, акцентный синий вместо
тёмной «аудит»-темы. Интерфейс рабочего журнала, а не витрины.

## ИЗМЕНЯЕМЫЕ ФАЙЛЫ

- `src/index.css` — палитра (светлый фон, серые линии, синий акцент),
  типографская шкала, плотные отступы
- `src/App.tsx` и секции — перенос на деловую сетку: шапка, левая навигация/список,
  основная область; убрать декоративные фоновые слои (noise/grid)
- Компоненты (`Terminal`, `Roadmap`, `ConformanceMatrix`, `TaskRegistry`, листы v0X) —
  приведение карточек, таблиц и статусов к деловому виду

## ЧТО СДЕЛАНО (что должно быть)

- Светлая тема, читаемая при дневном свете; контраст по WCAG.
- Акцент — один синий (деловой), статусы: зелёный/красный/серый без неона.
- Данные журнала (сборки, вердикты, реестр заданий) сохранены полностью —
  меняется только оформление, не содержание.
- Без центрированного hero-трио, без одинаковых карточек в ряд, без градиентных
  заголовков и glassmorphism.

## КОД

Будет приложен проектировщиком в момент выдачи (это переработка существующего
дашборда, не новый проект).

## ТЕСТ

1. Дашборд открывается в светлой деловой теме, все секции и данные на месте.
2. Статусы PASS/FAIL/ожидание различимы без цвета-неона.
3. Вёрстка устойчива на 1280–1920 px; шрифты кириллицы читаемы.

## ОЖИДАЕМЫЙ РЕЗУЛЬТАТ (PASS)

Строгий деловой вид в духе Gmail; содержание журнала не потеряно.

СТОП.
