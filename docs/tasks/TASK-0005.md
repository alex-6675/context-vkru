# TASK-0005 — chore(env): настройки workspace и рекомендации расширений

**КОММИТ:** `chore(env): настройки workspace и рекомендации расширений [TASK-0005]`
**СТАТУС:** ОЧЕРЕДЬ
**ОБЛАСТЬ:** `env` — окружение разработки
**ЗАВИСИМОСТЬ:** нет

## ЦЕЛЬ

Зафиксировать настройки рабочей области и рекомендуемые расширения VS Code,
чтобы окружение разработчика было воспроизводимым.

## ИЗМЕНЯЕМЫЕ ФАЙЛЫ

- `.vscode/settings.json` — настройки workspace (форматирование, файлы под наблюдением)
- `.vscode/extensions.json` — рекомендации расширений для проекта

## ПРАВИЛО КОММИТА (обязательно)

Изменения `.vscode/` коммитятся **отдельным коммитом** `chore(env): …` —
**не смешивая** с кодом расширения (`EdgeExtension/`) и дашбордом.

## ЧТО СДЕЛАНО (что должно быть)

- Настройки касаются только workspace, не глобальных пользовательских prefs.
- В `extensions.json` — только реально нужные расширения (ESLint/Prettier и т.п.).
- В коммит не попадает ничего из `EdgeExtension/` и `src/` (дашборд).

## ТЕСТ

1. Открыть проект в VS Code → применятся workspace-настройки, предложат расширения.
2. `git log` показывает `chore(env)` отдельным коммитом без файлов ext/dashboard.

## ОЖИДАЕМЫЙ РЕЗУЛЬТАТ (PASS)

Окружение воспроизводимо; коммит изолирован.

СТОП.
