## 1. Уточнение образца (важно, зафиксировал)

- «Камни с именами» — этоNiesky: русские в Германии восстанавливают утраченные имена; сайт n52a.de/memorial/niesky/list —карточки + данные + доказательства гибели + проверка в МО три года. Это и есть образец представительства и раздела «Согласование с Минобороны».
- Балаклава: инициатива нем. правительства — перезахоронить все останки в одном месте в Крыму (источник — персонаж поста 1 форума sgvavia.ru). Значит, поле «Откуда перезахоронен» — это ещё имаршрут останков: яма/высота → мемориал.

## 2. Ваш CSV — это уже база; карта в soldier v2

- Заголовок / last+first+middle →`name`;
- document_type + document_id + primary_url →`source {ЦАМО/obd, id, url}`=evidence(как в Niesky);
- rank →`rank_cat`(лейтенанты/политруки = офицеры; рядовые/сержанты = рядовые) — объясняет, почему 59 известных = офицеры;
- warunit →`unit`(398 сд, 404 сд — части участка);
- cause_of_death →`cause`(умер / пропал без вести / умер от ран);
- date_death →`death.date`;
- place_birth →`search_city`— нить к потомкам («г. Керчь, пер. Сенной 11», «Зав. Миньяр, ул. Якова Заикина 14»);
- primary_burial / current_burial →`burial.primary / burial.reburial`—дополняются со страницы obdполями «Откуда перезахоронен» / «Место захоронения»;
- nomer_fonda/opisi/dela → реквизиты (заполнятся позже).

## 3. Примеры действий (ответ на вопрос скрина)

1. Обогащение:`document_id`→ страница obd → вытащить «Откуда перезахоронен» + «Место захоронения» → в карточку. Бот извлекает, старший ставит клеймо.
2. Группировка под плиты:GROUP BY «Откуда перезахоронен» (выс. 66,3, Дальние Камыши, Ак-Монай…) → группа = одна яма = одна плита; сверка с рукописными журналами («высота 28,3»).
3. Фильтр участка:warunit ∈ {398 сд, 404 сд…} + date_death ∈ [дек 1941–июн 1942] + reburied_from в секторе → кандидат в 3310 «Копечь».
4. Нить к живым:last_name + place_birth → джуниор ищет в соцсетях → ответ да/нет/ожидание.
5. Верификация:список плит → МО (как Niesky: три года проверки) → approved → engraved.
