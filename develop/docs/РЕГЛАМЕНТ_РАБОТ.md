# РЕГЛАМЕНТ РАБОТ

Регламент организации рабочего процесса по проекту «Context VK.RU».

> КАРКАС: будет наполнен на этапе разработки.

## Основные правила

- Каждая рабочая сессия фиксируется отчётом в папке `reports/`.
- Скрипты сборки запускаются из `scripts/` (Build / Clean / Test).
- Реализация ведётся согласно `docs/architecture.md`.
